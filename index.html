How to use it

  1. Add the class snap-slider to the section that wraps your row.
  2. Replace .slider-track with your row container class and .slider-item with your item class.
  3. Paste the CSS from snap-slider.css inside your tablet and mobile breakpoints only.
  4. Desktop keeps your normal row. Done!

The CSS

/* Paste inside your tablet and mobile breakpoints */
@media (max-width: 1024px) {

  .snap-slider .slider-track {
    display: flex;
    justify-content: flex-start !important;
    flex-wrap: nowrap;
    overflow-x: auto;
    scroll-behavior: smooth;
    -webkit-overflow-scrolling: touch;

    /* One slide at a time */
    scroll-snap-type: x mandatory;
    scroll-snap-stop: always;

    cursor: grab;
    user-select: none;
    -webkit-user-drag: none;
    scrollbar-width: none;
  }

  .snap-slider .slider-track::-webkit-scrollbar { display: none; }

  .snap-slider .slider-track .slider-item {
    min-width: 75%;
    flex-shrink: 0;
    scroll-snap-align: start;
    scroll-snap-stop: always;
  }

  .snap-slider .slider-track * {
    user-select: none;
    -webkit-user-drag: none;
  }
}
